# 🚀 Analisador de Desempenho de Algoritmos de Busca

Projeto desenvolvido no 4º semestre de Ciência da Computação para comparar empiricamente a complexidade de tempo entre a **Busca Sequencial ($O(n)$)** e a **Busca Binária ($O(\log n)$)**.

## 🛠️ Tecnologias e Conceitos
- **Linguagem:** Java (POO)
- **Algoritmos:** Ordenação (Arrays.sort) e Algoritmos de Busca
- **Métricas:** Medição de tempo de execução via `System.nanoTime()`
- **Análise Assintótica:** Comparação prática de Notação Big-O

## 💻 Como executar
```bash
javac Main.java
java Main
